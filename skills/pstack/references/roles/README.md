# Agent roles

Read the matching prompt when delegating a pstack role. These are ordinary Codex agents with task-scoped briefs.

- [Implementation role](poteto-agent.md) follows the selected playbook and repository rules; report scope, changes, evidence, and open work.
- [Comment reviewer](comment-sicko.md) examines whether comments express a useful non-obvious reason or hide an unenforced constraint. Preserve license notices, required attribution, safety constraints, and scoped tool directives.

The parent retains ownership and reviews actual diffs. Role prompts never widen authority.
