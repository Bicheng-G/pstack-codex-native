# pstack help

Find the requested outcome, then point to the smallest matching action in [the index](../../index.md).

Start with `$pstack poteto-mode <task>` for guided engineering. Direct actions include how, why, architect, arena, swarm, interrogate, recall, tdd, and the verification-skill helpers. Use the original action names after `$pstack`; these internal guides do not register individual slash commands.

Explain current Codex capabilities and limits from [runtime](../../codex-runtime.md). No setup is required for inherited models. Model preferences are project-local workflow data. Independent or cross-model review depends on actual available/authorized delegation.

Do not start the proposed engineering task when the user asked only for help. Give a concrete invocation suited to their request.
