# Swarm

State the done predicate and choose coverage slices, a same-brief race, or a mixture. For a race declare `first pass`, `rank all`, or `best-of` before launching.

Create task-scoped briefs with goal, source pointers, exact slice, checkout and SHAs, permitted writes, verification method, expected evidence, and result schema. Each worker reports PASS, ISSUES, or BLOCKED. A measurement brief defines what one sample means, sample count, and execution order.

Use the current Codex delegation tools and inheritance defaults. Bound concurrent agents by available slots; queue excess slices. Isolate writers by verified checkout or disjoint paths. No implicit cloud machine or branch selection exists.

Join every launched worker. For coverage, every required slice needs evidence; a dropout is a gap. A report missing its named SHAs or measurement method is not valid coverage. One bounded corrected run may recover it; a second miss stays a gap. For a race apply the selection rule already stated.

Inspect evidence and produce one report with covered slices, proven issues, gaps/dropouts, relevant artifacts, and limitations. Do not claim an unavailable independence or model family. Reaching an agent limit does not authorize creating user-owned chats.
