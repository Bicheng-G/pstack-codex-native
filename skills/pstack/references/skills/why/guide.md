# Why

Investigate motivation and constraints. Use **how** for mechanism. Read [epistemics](references/epistemics.md) before synthesizing disputed historical conclusions.

Pin the target, question, time window, and project. State a reasonable interpretation if narrow ambiguity can be corrected while you work. Discover enabled connectors by their actual tool metadata. Search relevant source control, issues, decisions/docs, chat history, incidents, observability, and analytics only when they can bear on the question.

Use [source playbook](references/source-playbook.md) and the matching files under `references/sources/`. Queries may be batched independently; agents are optional and subject to current delegation rules. Never send messages or update external records as part of evidence gathering.

Each investigator uses [investigator prompt](references/investigator-prompt.md), owns an evidence category, and returns exact citations, null results, limits, and competing explanations. Synthesize using [synthesizer prompt](references/synthesizer-prompt.md).

Separate documented rationale, current code, production observations, and inference. Test or label contradictions rather than choosing the newest document. If history does not establish intent, say unknown.

For a planned change, derive Preserve / Change / Avoid / Risk constraints. Missing external sources limit confidence but do not justify inventing a cause.
