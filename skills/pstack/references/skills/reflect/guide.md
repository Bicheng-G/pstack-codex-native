# Reflect

When requested, extract durable learnings from the active conversation. Skip trivial or already-covered lessons; a one-off is not a general rule.

Use this conversation or a scoped Codex chat read. If exact transcripts are unavailable, provide a compact digest and label that evidence limit. Do not guess host transcript paths.

Review through three lenses using [judgment](references/judgment-reviewer.md), [tooling](references/tooling-reviewer.md), and [divergent](references/divergent-reviewer.md) prompts. Use permitted independent agents or clearly labeled sequential lenses. Synthesize with [synthesizer](references/synthesizer.md).

Route only to skills/tools actually used. Prefer architectural, type, lint, or runtime enforcement over repeated prose when it fits the demonstrated mistake. Classify Accepted, Rejected, and Backlog with evidence and proposed destination.

A reflection request alone yields concrete proposed edits. Apply only edits the user already authorized, or seek approval after showing the exact proposal. Keep backlog suggestions local unless external filing is authorized. Global memory writes obey the session's explicit memory rules.

For skill edits use the available **skill-creator** workflow and validate touched skills. Report actual changes, deferred items, and remaining evidence limits.
