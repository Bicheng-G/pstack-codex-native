# perf-issue

Pin the symptom, environment, representative workload, and performance metric. Capture a baseline trace and run **benchmark-checklist** before interpreting it. Identify the limiting resource and an evidence-backed hypothesis.

Change the bottleneck, capture the same trace and repeated measurements, verify correctness and end-to-end relevance, and report the range plus regressions and limits. Do not report a microbenchmark win as a product win. Use inherited-model implementation or permitted delegation rather than a provider-specific default.
