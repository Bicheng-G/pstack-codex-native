# autopilot-stack

Build a dependency-ordered linear stack for user review. The user owns landing unless separately authorized.

Give every unit its intended parent baseline. One root/stack owner controls chain topology; delegates write only assigned units. Publish PRs only under the user's Git grant, with each PR based on its dependency.

Verify each link against its actual parent. Reconcile drift bottom-up when authorized, and recheck all affected inputs and required CI. New heads do not silently inherit verdicts. Give the user root/tip links, per-link behavior and evidence, and unresolved gates.

Do not merge, arm auto-merge, close, force-push, or retarget merely to finish the stack. If the request only covers local preparation, deliver local changes and the concrete planned chain.
