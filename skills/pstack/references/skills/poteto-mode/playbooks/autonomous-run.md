# autonomous-run

State a falsifiable done predicate, scope, known grants, user gates, and a reasonable stopping budget. Choose the smallest relevant playbook or **figure-it-out**. Execute authorized work continuously, with meaningful progress updates and bounded retries.

Keep decisions/evidence only as needed for recovery or audit. Delegate when permitted and useful; join results and verify actual artifacts. User questions during work steer the task unless they clearly cancel it. An explicit pause/stop must be honored.

Autonomy does not grant new external, destructive, billing, data, or messaging rights. Make concrete reviewable preparation for any missing final authorization while continuing independent work. If work must continue after the turn, use a requested Codex automation; do not pretend an in-memory loop survives session exit.

Report actual outcome against the predicate, proof, partial work, and next blocked action.
