# autopilot-full

Use for an explicitly authorized independent PR queue. Pin queue membership, target branch, owner per PR, verification bar, and the exact merge grant. A planning request is not execution authority.

Build each independent unit on the correct baseline in its own verified checkout. Use Codex agents within the session cap when allowed. Keep recoverable briefs and exact head/evidence receipts. No implicit cloud execution exists.

The owner implements, proves behavior, prepares the PR, and works to readiness under the applicable Git grant. An independent verifier checks the finished head when required; the root inspects real artifacts. Batch proven findings to the owner, maintaining one branch writer.

After a new head or relevant base/dependency change, rerun affected verification and required checks. Neither a self-proof nor green CI replaces a required independent verdict. Never weaken a gate to make a unit merge.

Before authorized merge, recheck target, current head/base, checks, review and merge state. Only verified units within the explicit queue/grant land. Anything reserved for the user stops at its gate. Honor stop/hold across all agents and reconcile their final writes.

Use requested Codex automation for later monitoring only. Report each PR's actual state, receipts, merged SHAs, unresolved gates, dropouts, and limits.
