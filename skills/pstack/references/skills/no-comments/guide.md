# Review comments

Inspect the user's scoped files or diff. Use the [comment reviewer](../../roles/comment-sicko.md) as a read-only Codex agent when permitted, or perform the same review directly.

Identify comments that repeat code, describe obsolete paths, or assert a constraint without enforcement. Preserve legal/license text, attribution, safety constraints, supported tool directives, and non-obvious reasons. Investigate an ambiguous constraint with **how** or **why** before proposing removal.

Classify keep, delete, rewrite, or encode with evidence. Comment cleanup does not authorize application-code changes or expanding scope. For an authorized cleanup, make the smallest accepted edits. For a review-only request, report findings without writing.

Offer an in-scope type, test, lint, or runtime encoding when it would enforce a demonstrated constraint. Do not remove a still-needed constraint merely because its better enforcement is out of scope or lacks approval.

Verify changed behavior only if behavior changed; check comments/directives against their actual consumer when applicable. Report unresolved constraints honestly.
